 # albasma-al3tariya

 البصمة العطرية / Perfume Print

منصة رقمية لاكتشاف التفضيلات العطرية.

تساعد المنصة المستخدم على استكشاف ذوقه العطري من خلال أسئلة 
غير مباشرة (أجواء، أحاسيس، صور، مواقف)، دون الحاجة إلى 
معرفة النوتات أو المصطلحات التقنية.

## الرابط المباشر (Live Demo)

https://ismailach07-droid.github.io/albasma-al3tariya/v97.html
## الميزات

- مسار سريع (6 أسئلة) ومسار معمّق (12 سؤالًا)
- 159 عطرًا في ثلاث فئات (رجالي، نسائي، للجنسين)
- توصيات مبنية على 12 بُعدًا حسيًا
- لوحة عملاء + سجل اختبارات
- تصدير النتائج (CSV)
- واجهة عربية وفرنسية
